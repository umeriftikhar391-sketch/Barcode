# Odoo 19 Enterprise SaaS configuration

Use a dedicated least-privilege integration user with read access to product variants, sales prices, currencies and authorized pricelists. Your Odoo subscription must allow external API access. Generate an API key through Odoo's supported account settings; never send it in chat, screenshots or exported queues. Review expiry/rotation per your organization's policy.

Configure `https://your-company.odoo.com`, database and API key in the app running on Windows. The backend stores these through WinVaultKeyring / Windows Credential Manager; no plaintext fallback. Search/test fetches active currencies then product variants using read-only `search_read`. Missing barcodes must be corrected locally through manual entry or separately by an authorized Odoo operator. The app never writes names, barcodes, prices, inventory, variants or company settings.

For Linux development, inject ODOO_URL, ODOO_DATABASE and ODOO_API_KEY only into the backend environment. `.env.example` is a description, not an automatically loaded file. Disconnect removes stored Windows credentials; development environment variables must be removed from the launching process and the service restarted. Never use VITE_ variables for secrets. Logs intentionally avoid raw remote response bodies and authentication material.

Official documentation: https://www.odoo.com/documentation/19.0/developer/reference/external_api.html and its accessible source https://github.com/odoo/documentation/blob/19.0/content/developer/reference/external_api.rst. JSON-2 uses POST `/json/2/<model>/<method>`, `Authorization: bearer ...`, named JSON arguments and X-Odoo-Database as needed. Consult your own database `/doc` to verify exposed methods, field names, permissions, and supported pricing operations. Default Sales Price field is `lst_price` on `product.product`; database-specific differences must be diagnosed instead of guessed. Errors explicitly report HTTP status without leaking response tracebacks. No legacy XML-RPC/JSON-RPC adapter is used.

Selected Pricelist can list accessible records, but actual calculation is **blocked** until a public authorized API operation is confirmed for this database. Do not guess `_get_product_price` or replicate complex rule calculations from record lookups. Verify variant, quantity, effective date, partner, company and currency context in a dedicated adapter before enabling prices. `odoo.pricelist_price` raises an explicit limitation rather than returning invented prices. Current live API connectivity, field access, Sales Price semantics and pricelist operations have not been verified.
