# Inspection evidence

The starting Barcode repository was an empty unborn checkout with no tracked code. This development request authorizes creating application source after the earlier onboarding inspection.

* `Product Variant (product.product).xlsx`: inspected with openpyxl. Sheet1 has three rows, five columns: Barcode, Product, Quantity, Sales Price, Currency. Row 2: text barcode `1000704-01`, Kacha Opener Truck, stock-like quantity 636, explicit zero price, `$`. Row 3: numeric barcode `1000037`, Chamakpatti Bookmark Customized, quantity 32, price 850, `$`. Numeric leading zeros cannot be recovered reliably. A copy is retained in `tests/fixtures/odoo.xlsx` to exercise the actual import case. Quantities require explicit interpretation; they are not silently treated as label counts.
* `PDF.pdf`: all ten pages rendered and visually inspected. Pages 1–2 show Odoo label action/settings; page 3 identifies TE200; pages 4–5 show a separate Epson/POS device; pages 6–7 show the three-column roll and ruler; page 8 provides the centered Coaster barcode/price sample; pages 9–10 show Odoo barcode settings and built-in formats. Photos do not resolve precise contradictory measurements. Design follows centered name, barcode, exact human-readable value and bold price; chosen symbols take precedence over sample `PKR` wording.
* `tsc_12.4.0.zip`: download tool rejected the file because it exceeds its 32 MiB transfer limit. No archive metadata, executable signature, publisher or checksum was inspected. No executable was run. Inspect on Windows using `Get-AuthenticodeSignature` and compare the official manufacturer's current package before installation. A valid signature alone does not establish suitability for TE200/Windows x64.

Stated dimensions are preserved: 3×35 + 2×2 + 2 + 2 = 113 mm, but backing is 107 mm and maximum printable width is 108 mm. Three 35 mm labels alone leave only 2 mm across a 107 mm backing for all gaps and margins. No corrected value is inferred. Confirm backing width, actual die-cut width/height, both horizontal gaps, side margins, vertical gap, printer origin and offsets. Default production printing is blocked.

Official Odoo website documentation and TSC product page returned HTTP 403 in this environment. The official Odoo documentation source was subsequently retrieved from https://raw.githubusercontent.com/odoo/documentation/19.0/content/developer/reference/external_api.rst and confirms `/json/2/<model>/<method>`, bearer authentication, optional X-Odoo-Database and database `/doc`. Per-database fields, permissions and pricelist pricing are still unverified. TSC specifications and TSPL commands have NOT been independently checked against the current official model manual; direct mode requires an explicit operator confirmation of that check, plus physical tests.
